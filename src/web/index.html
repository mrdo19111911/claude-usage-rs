Claude accounts

Each account has two logins side by side. Claude CLI (terminal and VS Code share one login) switches at once. Claude Desktop closes the app and opens it again on that account (running tasks stop); the first time, it opens signed out: click Continue with Google there and choose the account. Their auto-switch switches: Claude CLI moves to this account when the one in use nears a limit; Claude Desktop only when its account has reached a limit (100%). Charts: each window from its start to its reset; the dotted diagonal is an even pace.

Claude Code on Gemini

Use Claude Code for free: Google's Gemini answers instead of Claude. Your Claude accounts stay as they are.

Add a free Gemini account

Google's page opened in a new tab. Not there? Open Google's page again

With a free key, Google may read what you send through cgemini, your code too, and use it to improve its models. Do not use it for code that must stay private.

  1. Sign in with your Google account on the page that opened (and accept Google's terms if asked).
  2. No code yet (the first time)? Press Create API key. If it says “No Cloud Projects Available”, choose Create project, press Create project again (keep the name), then Create key. Already see a code in the list? Then skip this step.
  3. Next to your access code, press the Copy button (two small squares).
  4. That's it: this window picks it up by itself.

The access code is free, from Google. Google's page calls it an “API key”. The app checks it with Google, then keeps it on this computer only.
